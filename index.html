How to run it locally:

The project is fully open-source. You can easily launch it on your machine using Docker with just three commands: 

git clone https://github.com/Volynskyi-Kirill/Codexion-Visual-Replayer.git
cd Codexion-Visual-Replayer
docker compose up -d --build

Then, open http://localhost:3000 in your browser.
